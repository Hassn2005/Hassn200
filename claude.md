# Dantil — Premium Accessories Landing Page

## Project name
Dantil

## Brand
- Brand name: Dantil
- Location: Daraa, Syria
- Business type: Women’s accessories boutique
- Audience: Premium, style-conscious women seeking refined everyday accents

## Tech stack
- React.js
- TypeScript
- Vite
- Tailwind CSS
- React Helmet Async
- Lucide React

## Design direction
- Elegant + feminine + premium + modern + editorial + sophisticated
- Luxury boutique aesthetic rather than childish or generic fashion template styling
- Soft blush, dusty rose, warm ivory, warm charcoal, muted mauve, champagne accents, deep plum contrast
- Editorial typography paired with clean modern UI hierarchy

## Required sections
1. Navbar
2. Hero
3. About Us
4. Features
5. Our Location
6. Contact Us
7. Last Welcoming Section
8. Footer

## Functional limitations
- No backend
- No database
- No API integration
- No authentication
- No cart or checkout
- No real contact form
- Static content only

## SEO requirements
- React Helmet metadata with title, description, keywords, theme-color, og/twitter metadata, and language metadata
- Light keyword usage without stuffing
- Premium brand polish in metadata

## Responsive requirements
- Mobile-first layout optimized for 320px–430px widths
- Tablet and laptop adjustments through larger breakpoints
- Large desktop and ultra-wide screens handled with controlled max widths and intentional spacing
- No horizontal overflow

## Important decisions
- Floating island navbar with hide/show scroll behavior for premium motion
- Subtle, non-distracting animations consistent across sections
- Remote editorial imagery selected to match the feminine boutique brand direction
- Static contact cards instead of a form
- Reusable data-driven content for nav, features, and contact information

## Current implementation status
- Project scaffolded successfully
- Tailwind integration added
- Brand planning and content structure documented
- Landing page sections being built to match the Dantil brief

## Known issues
- None yet
